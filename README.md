# Unit Converter

A small Python program that converts common units from the command line.

## What it does
- Kilometres ↔ miles
- Kilograms ↔ pounds
- Celsius ↔ Fahrenheit

## How to run
1. Install Python 3
2. Download `main.py`
3. Run: `python main.py`
4. Pick an option and enter a value

- Writing functions in Python
- Using a dictionary to build a menu
- Taking input and formatting output
